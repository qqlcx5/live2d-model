## 📖 项目简介

本仓库整理了多款可直接嵌入博客、静态文档站点或个人主页的优质 Live2D 看板娘模型资产。包含模型配置文件、动作动画（Motions）、表情贴图与交互音效。

---

## 🎭 收录模型清单

- 🌸 **Sagiri（和泉纱雾）**：经典超人气萌系看板娘，支持点击触碰交互与换装。
- 💙 **Rem（蕾姆）**：从零开始的异世界生活主题模型。
- 🌾 **Xiaomai（小麦）**：清新元气互动模型。

---

## 🚀 部署与使用

仓库内置自动化部署脚本 `deploy.sh`，可将模型资源一键托管到个人静态 CDN 或 GitHub Pages，方便站点快速跨域引用。
